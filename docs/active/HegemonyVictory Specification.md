# 霸权胜利（Hegemony Victory）规格

霸权胜利是《文明 VI》的独立胜利方式。当一个文明在总分、各项产出、军力、世界奇观和城邦宗主权上同时达到要求时，游戏自动结算为霸权胜利。

## 开局设置与胜利判定

- 高级设置的胜利条件中提供「霸权胜利」复选框，与原版分数胜利分别设置。勾选后启用自动判定和独立进度面板，取消勾选时停用判定并隐藏面板入口。
- 所有时代均可达成霸权胜利。每次判定使用同一时点的数据，所有条件须同时满足。游戏已有胜者时，以已结算的结果为准。
- 达标后由 Gameplay 自动发起结算，胜利类型为 `VICTORY_HEGEMONY`。局内面板用于查看进度。

### 达标条件

产出按每回合数值统计。总分、产出和军力的对手范围是仍存活的其他主要文明，包含尚未相遇的文明。数值比较均使用严格大于，恰好相等时未达标。

| 指标 | 统计口径与达标条件 |
| --- | --- |
| 总分 | 游戏总分严格高于总分最高的对手。 |
| 食物、生产力 | 分别汇总各文明所有城市的每回合食物产出和生产力产出，每项均严格高于该项最高的对手。 |
| 科技、文化、信仰 | 每项产出均严格高于其他主要文明在该项的合计。 |
| 净金币 | 每回合金币产出扣除总维护费后，严格高于其他主要文明的**正净收入合计**。对手净收入为零或负数时按零计入。 |
| 军力 | 严格高于其他主要文明的军力合计，采用原版外交条的军力口径，排除国库金币。 |
| 世界奇观 | 当前拥有的已完工世界奇观超过全图已完工世界奇观的一半。统计建筑类世界奇观，征服取得的奇观归当前所有者。全图已完工数量为零时自动满足。 |
| 城邦宗主权 | 当前担任宗主的城邦数量超过全图当前有宗主的城邦数量的一半。统计存活城邦，全图没有城邦拥有宗主时自动满足。 |

科技、文化、信仰和军力的过半条件可直接写成「本方数值大于对手合计」。净金币也用这一比较式，对手合计只取正净收入。例如本方净赚 `80`，三个对手为 `90`、`-20`、`-10`，参照值是 `90`，本方未达标。零分母特判仅用于世界奇观和城邦宗主权。

## 进度与结算界面

- 局内通过新增 UI Context 注册独立的「霸权胜利」面板。每项显示本方数值、比较基准及达标状态。奇观和城邦显示拥有数、全图计入数量和过半所需数量。全图计入数量为零时显示「自动满足」。
- 结算页用原版布局展示「霸权胜利」、获胜文明和胜利短文，复用分数胜利的 `Time.bk2` 和原版配套音效。逐项指标由局内进度面板展示。
- 使用独立的 `ICON_VICTORY_HEGEMONY`。图案为戴金色三尖冠冕的深靛蓝地球，海岸保留可识别的真实轮廓，冠带沿球面弯曲。面板与结算页共用这枚图标，按 `64×64` 和 `80×80` 准备透明贴图，加载方式可参照 [推恩令图标定义](../../DividingGrace/UI/DividingGrace_Icons.sql)。

## 实现前仍需确认

| 事项 | 建议或待验证点 |
| --- | --- |
| 开局默认值 | 建议默认不勾选，由玩家决定本局是否启用。 |
| 自动判定时点 | 建议在新一轮全局回合开始时统一检查一次，避免在各文明行动过程中分开比较。需要实测判定时点与其他胜利结算的先后关系。 |
| 适用玩家与规则集 | 建议首版在《风云变幻》单人局验证人类和 AI 同等适用。没有剩余主要对手时，建议由原版胜利流程结算。 |
| 奇观被毁后的分母 | 建议以全图当前仍存在的已完工奇观为准。需要确认是否接受拆毁奇观会降低过半门槛。 |
| 军力数据 | 原版所用 `GetMilitaryStrengthWithoutTreasury` 在 UI 侧可读。实测 Gameplay 如何在判定时获取与其余指标对应的军力数据，尤其是 AI 和尚未相遇的文明。 [GameCore 军力接口](https://cru121.github.io/civ6-gamecore-reference/lua/PlayerStats.html) |
| 自定义胜利结算与界面 | 验证独立开局选项、自定义胜利类型和独立面板能够配合。原版世界排名可能为已启用的自定义胜利生成通用页，需验证独立面板能否避免重复入口与界面覆盖。用测试局确认 `Game.SetWinningTeam` 的胜利事件、战报名称与图标、原版动画和名人堂记录。 [GameCore 胜利接口](https://cru121.github.io/civ6-gamecore-reference/lua/Game.html) |

## 验收场景

- 分别用开启和关闭霸权胜利的配置新开局并读档，检查该设置是否持续控制面板入口和自动判定。单独开启霸权胜利并关闭原版分数胜利，仍可按霸权胜利规则结算。
- 总分第一、某一项打平或落后时继续游戏。各项同时达标时自动结算一次，胜利类型显示为「霸权胜利」。
- 分别覆盖奇观和城邦总数为零、恰好一半和严格过半。核对未完工奇观、征服取得的奇观和无宗主城邦的计数。
- 用含负净收入对手的场景验证净金币口径，并在一对一和标准规模地图中观察达标时机。
- 检查玩家获胜与对手获胜两种结算视角，以及中英文界面中的名称、图标和动画。发布前将最终规则同步到中英文 README。
