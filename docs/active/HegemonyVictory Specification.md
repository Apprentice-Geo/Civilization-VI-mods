# 霸权胜利（Hegemony Victory）规格

霸权胜利是《文明 VI》的独立胜利方式。当一个文明在总分、各项产出、军力、世界奇观和城邦宗主权上同时达到要求时，游戏自动结算为霸权胜利。

## 开局设置与胜利判定

- 高级设置的胜利条件中提供「霸权胜利」复选框，默认勾选，与原版分数胜利分别设置。勾选后启用自动判定并在世界排名显示进度，取消勾选时停用判定并隐藏对应入口。
- 首版支持《风云变幻》规则集下的非组队对局，涵盖单人、联机多人和热座。人类和 AI 的主要文明适用同一套条件。只剩一个主要文明时，由原版胜利流程结算。
- 自动判定仅在两个时点运行。每个全局回合开始时统一检查一次。每次攻占城市后，等城市归属及相关数据更新完成，再统一检查一次。产出、奇观和宗主权等指标的其他变化在下一次判定时一并计算。
- 所有时代均可达成霸权胜利。每次判定使用同一时点的数据，所有条件须同时满足。游戏已有胜者时，以已结算的结果为准。
- 判定时发现任一文明同时达标，由 Gameplay 立即发起结算，胜利类型为 `VICTORY_HEGEMONY`。世界排名用于查看进度，联机和热座均以 Gameplay 的结算结果为准。

### 达标条件

产出按每回合数值统计。总分、产出和军力的对手范围是仍存活的其他主要文明，包含尚未相遇的文明。数值比较均使用严格大于，恰好相等时未达标。

| 指标 | 统计口径与达标条件 |
| --- | --- |
| 总分 | 游戏总分严格高于总分最高的对手。 |
| 食物、生产力 | 分别汇总各文明所有城市的每回合食物产出和生产力产出，每项均严格高于其他主要文明在该项的合计。 |
| 科技、文化、信仰 | 每项产出均严格高于其他主要文明在该项的合计。 |
| 净金币 | 每回合金币产出扣除总维护费后，严格高于其他主要文明的**正净收入合计**。对手净收入为零或负数时按零计入。 |
| 军力 | 按判定时各文明的现有单位计算。每个单位取近战和远程强度中的较高值，按剩余生命值比例折算，再将该文明的单位贡献求和并向下取整。国库金币不计入。本文明军力须严格高于其他主要文明的军力合计，进度面板采用同一口径。 |
| 世界奇观 | 当前拥有的已完工世界奇观超过全图当前仍存在的已完工世界奇观的一半。统计建筑类世界奇观，征服取得的奇观归当前所有者。奇观被毁后从分子和分母的统计中移除，过半所需数量随剩余总数重新计算。全图计入数量为零时自动满足。 |
| 城邦宗主权 | 当前担任宗主的城邦数量超过全图当前有宗主的城邦数量的一半。统计存活城邦，全图没有城邦拥有宗主时自动满足。 |

食物、生产力、科技、文化、信仰和军力的过半条件可直接写成「本方数值大于对手合计」。净金币也用这一比较式，对手合计只取正净收入。例如本方净赚 `80`，三个对手为 `90`、`-20`、`-10`，参照值是 `90`，本方未达标。零分母特判仅用于世界奇观和城邦宗主权。

## 进度与结算界面

- 启用时在世界排名总览和胜利页签各显示一次霸权胜利，沿用原版布局、切换和关闭行为。文明按十项条件的达标数降序排列，达标数相同的文明按玩家 ID 稳定排列。详情在本方条目下方用四列表格显示指标、数值、比较基准和达标状态。奇观和城邦显示拥有数、全图计入数量和过半所需数量。全图计入数量为零时显示「自动满足」，并计入达标数。
- 结算页用原版布局展示「霸权胜利」、获胜文明和胜利短文，复用分数胜利的 `Time.bk2` 和原版配套音效。逐项指标由世界排名的霸权胜利页签展示。
- 霸权胜利徽章直接复用原版通用胜利的金色地球。图标键 `ICON_VICTORY_HEGEMONY` 指向 `ICON_VICTORY_UNIVERSAL` 的同一图集位置，名人堂、局内进度和结算页从原版图集读取对应尺寸。

## 开发阶段实测

| 事项 | 验证内容 |
| --- | --- |
| 判定事件与结算顺序 | 实测全局回合开始和攻占城市后各自适用的 Gameplay 事件，确认两个时点的判定数据均已更新，且每个全局回合开始和每次攻占城市各判定一次。验证同一操作同时达成霸权胜利与原版胜利时的结算顺序。 |
| 军力数据 | 验证 Gameplay 和世界排名能按同一口径统计现有单位，覆盖 AI 和尚未相遇的文明。检查单位受伤、恢复和国库金币变化时的数值。 |
| 自定义胜利结算与界面 | 验证独立开局选项、自定义胜利类型和世界排名能够配合。用测试局确认 `Game.SetWinningTeam` 的胜利事件、战报名称与图标、原版动画和名人堂记录。 [GameCore 胜利接口](https://cru121.github.io/civ6-gamecore-reference/lua/Game.html) |

## 验收场景

- 确认新建游戏时霸权胜利默认勾选。分别用开启和关闭霸权胜利的配置新开局并读档，检查该设置是否持续控制世界排名入口和自动判定。单独开启霸权胜利并关闭原版分数胜利，仍可按霸权胜利规则结算。
- 在中文界面确认其他胜利全部开启时，世界排名总览和页签各有一个霸权胜利入口，右上角独立按钮已移除。打开详情检查文明排序、本方十项明细和刷新，再切换至原版页签并关闭世界排名。
- 从独立面板版本更新时，完整退出游戏后重新启动再读档。若游戏进程仍使用旧清单，`Lua.log` 会报告已移除的 `HegemonyVictory_PartialScreenHooks.lua` 无法读取，右上角原版按钮及外交统计条会受影响。
- 总分第一、某一项打平或落后时继续游戏。分别验证在全局回合开始时和攻占城市后的判定中，所有条件均满足时立即结算一次，胜利类型显示为「霸权胜利」。奇观完工或宗主权变化补齐最后一项条件时，确认在下一次规定的判定时点结算。只剩一个主要文明时，确认由原版胜利流程结算。
- 分别覆盖奇观和城邦总数为零、恰好一半和严格过半。核对未完工奇观、征服取得的奇观和无宗主城邦的计数。验证奇观被毁后，其原所有者的拥有数、全图已完工数量和过半门槛按剩余奇观更新。
- 用含负净收入对手的场景验证净金币口径。用至少三个文明的对局验证食物和生产力分别超过每个对手但未超过合计时均未达标，并在一对一和标准规模地图中观察达标时机。
- 在联机同时回合和热座中分别验证两个判定时点，确认各玩家看到相同的胜者与胜利类型。
- 检查玩家获胜与对手获胜两种结算视角，以及中文界面中的名称、图标和动画。其他语言的界面验收根据发布后反馈补充。发布前将最终规则同步到中英文 README。

## 开发实测记录

- v4 已完成中文界面实测，未发现界面问题。
- 独立面板版本在本机风云变幻 DX12 版已确认霸权胜利默认勾选。关闭分数胜利后可查看进度，世界排名未生成重复页。构造全部达标的六文明对局后，日志确认第 2 个全局回合开始自动结算一次。
- 攻城实测确认 `CityConquered` 发生在城市易主后，随后 `OnCombatOccurred` 发生在战斗更新完成后。防守区在后一个事件中可能已删除，回调不一定返回原所有者 ID。正式实现按进攻方关联两个事件。尚待用实际达标的攻城局验证结算，以及同一次攻城触发原版胜利时的优先顺序。
- `Game.SetWinningTeam` 接受自定义胜利在 Gameplay 数据库中的索引。测试局已收到 `TeamVictory`，名人堂数据库记录了 `VICTORY_HEGEMONY`。正式版两种视角的结算显示、名人堂详情和动画仍需目视验收。
- 本机确认 Gameplay 无法读取外交条的 `GetMilitaryStrengthWithoutTreasury`。进度面板与 Gameplay 直接读取各文明的单位，并共用军力计算。 [GameCore 军力接口](https://cru121.github.io/civ6-gamecore-reference/lua/PlayerStats.html)
- Lua 回归检查已覆盖打平、对手正净收入合计、奇观严格过半和城邦恰好一半、两个零总数。仍待实测存读档的选项状态、奇观易主与被毁、宗主权变化、热座和联机同时回合。封面由作者补充。
