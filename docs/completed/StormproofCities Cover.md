# 安如磐石（Stormproof Cities）封面提示词

为《文明 VI》mod「安如磐石」绘制一张 1:1 正方形工坊封面，采用中国写实古风厚涂插画。以高位斜俯视展现一座建在平原上的古代中国城池，一条驿道穿过城门，向画面前方延伸。城池和田地都与周围大地相连。画面中心是一层罩住整座城及近郊农田的透明半球形防护罩，罩脚贴着地面。用一圈细金光勾出穹顶弧线，受风雨冲击的一侧泛起浅浅涟漪，其余罩面清透，让人看清里面的城楼、瓦舍和农田。罩内日光温暖，屋脊完整，树梢平静，田渠清澈。

让八种灾害围绕同一座城展开，在一幅连贯的山河全景里各有清楚的轮廓。

- **左后方**，火山正在喷发，山口迸出熔岩，暗红熔流沿山坡而下。山脚另一片林地已燃起森林大火，火线沿树冠蔓延，能看清成排燃烧的树木。
- **远处海湾上空**，飓风的宽阔螺旋云带环绕着清晰的风眼。靠近右侧平原，另有一道细长的龙卷风漏斗从云底直触地面。用横向盘旋的云带和纵向下垂的漏斗区分这两种风暴。
- **两侧山麓**，一侧是土黄色沙尘暴，沙墙滚过荒坡，半掩驿道；另一侧是冷蓝色暴风雪，密集的斜向飞雪掠过积雪松林。
- **近处地面**，一侧河水漫过堤岸，褐色洪峰冲到罩脚，沿着弧形边界向两旁分流。另一侧遭遇干旱，龟裂的田泥、枯黄的作物与罩内紧邻的青绿农田清晰相接。

让八种灾害停在罩外。用同一地平线、山势和河道串起各处景象，把最清晰的轮廓和最温暖的光留给罩中的城池。画面上方留出一片较暗、平静的天空。顶部居中写中文主标题「安如磐石」，四字用有碑刻棱角的金色大字；正下方居中写英文副标题「Stormproof Cities」，用较小的金色衬线字，两端各配一条短金线。标题与穹顶之间留出空隙。全图文字仅此两行。
