# Civilization VI UI 与本地化约定

除非任务另有说明，以目标规则集下实际加载的原版同类界面为准。实现前对照本机游戏的 XML、Lua 和本地化，确认界面结构、正常入口和各状态的显示方式。

## 界面与交互

- 优先把新功能接入已有页面和扩展点。自定义胜利的摘要放在世界排名「总体」，逐项指标放在对应详情页签。沿用原版的页签切换、关闭、刷新和滚动行为，按模组开关和适用条件控制入口。
- 优先复用原版控件、样式和可用的游戏资源。涉及图标时，核对各界面实际使用的图集、尺寸和可见比例。结算等已有流程也优先接入原版布局和配套演出。
- 表头和数据行应对齐列位置和可见宽度。动态内容排版后，按实际尺寸更新所属 Context、外层卡片和滚动区，保留底部间距。在有溢出菜单的页面新增页签时，确认页签过多时入口仍可访问。
- 摘要沿用原版同类状态及其信息可见性。以世界排名为例，本方领先、已相遇文明领先、未相遇玩家领先和无可用进度时分别复用原版文案。本方未领先且参与排名时，按原版格式显示本方名次。未相遇时沿用原版匿名名称和图标。

## 命名与说明

- 同一功能在设置、总览卡片、详情标题和结算等位置使用统一的正式名称。窄页签按原版同类标签使用简短名称。原版已有的产出名称、状态、提示和通用句式优先直接引用本地化键。
- 总览突出当前状态，具体数值和规则放在详情或悬停提示。数值使用游戏本地化格式，整数省略小数位，小数保留判断所需的精度。数量和总量清楚时可直接显示为 `2 / 5`。
- 按界面用途说明玩家需要知道的适用对象、触发时机和实际条件。比较条件写清对手范围、最高值或合计、严格或含等号的门槛，以及会改变结果的例外。代码实现细节留在开发文档或注释中。
- 进度展示和玩法判定共用统计口径。模组指标沿用原版术语时，如计算范围有玩家可感知的差异，应在对应说明中交代。改规则或名称后，同步核对中英文键、相关界面、`.modinfo` 简介和两份 README，确保各处语义一致。

## 游戏内验收

按改动范围对照原版对应界面。检查中英文、常用 UI 缩放、较长文本和内容较多时的布局。涉及世界排名时，覆盖对应的领先、未相遇和空状态，并检查切换页签、刷新回合或读档后的显示。修改 `.modinfo` 中的 UI 脚本入口后，完整重启游戏再验证加载结果。
